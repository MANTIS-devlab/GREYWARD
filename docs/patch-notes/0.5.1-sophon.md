The initial composition was correctly withheld by a stale final-media substring
check that still required the retired disable-only Flathub helper. The factory
now requires the whole normalized canonical helper, retaining trusted online
origin restoration and rejecting an old helper, removed EXIT trap or altered
signature restoration. The normal source/offline/media gates were rerun.

Validation includes both essential PowerShell gates, 74 current Windows image
tests (12 explicit platform/fixture skips), all 45 current native image/offline
tests, capture-boundary tests (three, including native
compositor capture/revocation), region
geometry/PNG (six), migration (five), broker readback (two), Flatpak compatibility
(four) and USB payload inputs (11). Two actual offline Flatpak origin tests cover
success and failure. The extracted Center 120 posture helper also passes four
reads spaced 12 seconds apart in a network namespace: no `firewall-cmd` fallback,
no authorization call, and no stale secure result when its provider disappears.

Sidecars contain provenance, SHA-256 and `verification.json`. Local commits are
preserved without publication. The existing public main's
[Source validation run](https://github.com/MANTIS-devlab/GREYWARD/actions/runs/40041347333)
is green for its own earlier commit; it is not CI for the unpublished Sophon
source.

## Acceptance boundaries

The reference validates the desktop, application installation and screenshot
interaction. It does not validate a fresh Sophon install. Both
`installed_system_tested` and `clean_vm_installation_tested` remain false.
SELinux remained Enforcing on the build host; its active desktop was not closed
or replaced. Fresh installation, reboot/recovery and physical multi-output
acceptance remain open. Public publication and booting a VM are separate
actions, not part of this image-construction request.
