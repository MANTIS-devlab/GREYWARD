# GREYWARD 0.5.6 Sophon

Prerelease installer for Fedora 44 x86_64, Labwc and DankMaterialShell 2.0.
Boot the installation media in UEFI or legacy BIOS mode, then select and
confirm the keyboard layout before configuring disk encryption.

## Changes since 0.5.5

- **Installer:** The keyboard confirmation runs before Anaconda starts storage
  configuration. The confirmed layout is carried into the normal and rescue
  initramfs so the same layout applies when unlocking the installed system.
  The installer-only boot menu offers normal installation, media verification
  and diagnostic logging. Installer screens and Plymouth use GREYWARD branding.
- **Security Center:** Backup distinguishes a mounted drive from a present and
  verified repository. Recovery and Update Center check their operation state
  before proceeding. Acknowledging a failed required control leaves the failure
  visible in the protection rating. Detection ownership survives scan-history
  pruning, and Network Activity filters the frozen list while paused.
- **Desktop and services:** Updated DMS status cards, protected-session focus
  handling and Administration terminal behavior. The DNS state read uses
  cached status. The OpenSnitch control-plane service, automated updates and
  threat-feed refresh include reliability fixes.
- **Office:** The Writer, Sheets, PDF and Slides builds from ArtCraft remain at
  the validated release-16 packages from 0.5.5. Their exact [source RPMs][office]
  remain available with that release.

## Validation

The final ISO passed the media checksum and offline payload checks. The
standard and diagnostic BIOS entries, the UEFI media-check entry, and a
Hyper-V Generation 2 boot reached keyboard confirmation on the final ISO.

The complete BIOS install and encrypted AZERTY unlock with an accented
character used an earlier 0.5.6 build. Normal and rescue QWERTZ unlock were
also exercised on an NVMe test VM. These results cover those tested paths.
Physical GPU, Wi-Fi and firmware coverage is still limited. Bazaar Explore
connectivity remains a known issue.
