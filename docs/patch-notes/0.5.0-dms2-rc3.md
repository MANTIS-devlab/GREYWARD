# GREYWARD 0.5.0 DMS2 RC3

This is a prerelease installer candidate, not a stable release or a completed
clean-install/security acceptance claim. The latest source also contains later
notification work which is **not included in this ISO**.

## Included in the ISO

- DMS 2.0 desktop integration with Labwc, the captured GREYWARD taskbar/Overview
  defaults, semantic security cards and Strata as the only public file manager.
- The disconnected-network Polkit loop correction: ordinary firewall health
  refreshes use a fixed read-only system service method. They no longer invoke
  the desktop firewall command that can request authorization. Provider failure
  remains uncertain; policy mutations still require authorization.
- The accepted GREYWARD Polkit panel, including its native emblem and working
  Cancel action on external screens.
- The accepted protected lock appearance: GREYWARD wallpaper, native clock/date
  and input, synchronous immutable settings and software-rendered background.
- OBS, QTerminal and Haruna are excluded from default installation.

All packages target Fedora 44. The checksum and provenance accompany the image.
The media and eight selected RPMs were verified, including both embedded copies
of each RPM. Installer dependency resolution and offline payload checks pass.
The packaged firewall regression passed four ordinary-user offline samples at
12-second intervals plus provider loss in an isolated bus/network namespace.
This does not prove the physical desktop's disconnected-network behavior.

Fresh clean installation, physical offline, complete three-screen, recovery and
performance acceptance of this exact image remain unestablished. The provenance
therefore retains `installed_system_tested: false`. The protected Polkit and lock
visuals were separately accepted on the physical reference.
