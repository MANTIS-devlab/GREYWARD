## Changes since 0.5.2

- The accepted Security Center plugin presentation is packaged in DMS 7.11,
  with temporary cache overrides retired.
- Network Activity and Updates display corrected protocol/port and provider
  punctuation. Read-only DNF queries handle the first configured metadata-key
  import without a TTY. RPM/metadata signatures and apply authorization remain
  required; the change does not install updates without authorization.
- Files 21 preserves desktop icon arrangements separately for connected-screen
  configurations, including repeated three-to-one-to-three output transitions.
- Plymouth displays the appropriate shutdown/reboot label. The protected
  desktop startup transition uses graphite surfaces and the GREYWARD emblem,
  keeping its existing readiness and protected-input boundaries.
- Writer 0.11.0, Sheets 0.12.1, PDF 0.14.0 and Slides 0.11.1 are independent
  signed revision-9 RPMs. Credit for their engines and interfaces belongs to the
  ArtCraft authors and upstream contributors. GREYWARD provides downstream
  packaging, identity, artwork, dark surfaces and desktop integration; these
  customized builds are not official ArtCraft releases.
- The signed GitHub Office channel is enabled for future installations. The
  pipeline checks stable upstream releases every 144 hours, builds/tests the
  complete four-app family and retains three generations with 48-hour expiry
  grace. Incompatible source/patch/license inputs block promotion. The existing
  DNF5 Update Center owns installation and its normal offline/restart workflow;
  no Office-specific privileged updater or forced reboot is added.

The image retains 0.5.2's accepted desktop layout and palette, separate Office
application/document icons, trusted exact factory shortcuts, Software dock pin,
Strata-only file management, protected USBGuard/Polkit and lock designs, offline
firewall/Polkit-loop correction, update/privacy notifications, Bazaar Explore/
Flatpak-origin recovery and mouse-area screenshots with protected-frame exclusion.
OBS, QTerminal, Haruna, Collabora and Papers remain outside default selection.
Personal accounts, VPN profiles/MTU/keys, developer tools and SSH server access
are not image defaults.

## Sources and verification

The frozen archive contains 4,752 project source/build files and an explicit
per-file manifest, original/published hashes and executable modes, bound to
engineering commit 535652d. Private Git history and host-access configuration
are excluded; documentation is sanitized. No non-document source bytes change
during export. The original Center/Context source fingerprint is
`984e167bca4fe5b81c9a1e250bda36338b3f14f58c9d714fa7cc3ee4c131a6c6`.
Use these frozen inputs for this ISO; later GitHub main can contain newer work.
The four accompanying signed Office source RPMs contain the prepared engines,
GREYWARD adaptations, locked vendored Cargo dependencies, fonts/resources and
original notices. Other upstream inputs are pinned by their owning manifests.

Linux composition, networkless RPM/Flatpak verification and Windows media
readback pass. The Windows copy matches the builder SHA-256; all thirteen selected
RPMs match in both embedded locations (26 comparisons), with nine canonical-file
checks, forty required paths, all payload hashes and the enabled pinned Office
channel checked. This is not a bit-reproducible or signed-ISO claim.

Complete clean-install, recovery, physical printing, actual shutdown/startup
visual observation and broad hardware acceptance remain separate. New Office
versions pass native document round trips and packaged offline GUI/listener
checks; physical editing/clipboard/printing of these versions is not implied.
Complete Microsoft Office/LibreOffice compatibility is not promised.

Verify `sha256sum -c GREYWARD-0.5.3-Sophon-x86_64.iso.sha256`, or compare
PowerShell `Get-FileHash` with the SHA-256 above. Provenance and media verification
JSON accompany the release. SourceForge transfer/readback evidence is recorded
separately from composition; publication does not establish installed acceptance.
