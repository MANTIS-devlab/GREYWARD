## Changes since 0.5.4

- Network Activity: Live polling resumes correctly after navigation; retained
  connections are reassessed as new evidence arrives, and focused row controls
  no longer leave old risk badges on screen. Mixed exact-process and application/
  UID attribution no longer splits a single observed discovery pattern.
- Risk assessment: bounded service/host-discovery patterns and fresh local
  IP-and-port reputation indicators contribute explainable scores on the existing
  1–6 scale. Policy decisions, severity, confidence and sensor health remain
  separate. Tor, privacy tools, unusual ports or denials alone do not establish
  malicious behavior. No heuristic score automatically blocks or kills a process.
- Country flags: local IPv4/IPv6 MMDB lookups, graceful handling of local/reserved
  destinations, bounded caching and a recovering monthly database updater.
  Normal lookups do not send connection destinations to a geolocation service.
  Database and flag attribution remain included with their owning components.
- Polkit: prepared multi-output keyboard-focus handoff correction in the matched
  Runtime 88 / Enrollment 91 fresh-install packages. This is not a claim that
  every intermittent authentication failure has the same cause.
- Boot/update visuals: native Plymouth parser and kernel-update guards preserve
  the custom theme. Linux text/interpreter checks catch the identified packaging
  defects. The ISO's native media checksum is now implanted and verified, fixing
  the known missing-checksum failure of 0.5.4's Test-media entry.
- Desktop icons: a failed automatic storage mount no longer leaves a blocking
  dialog in the desktop-icons process. Normal Strata/manual mounts remain.
- Office: validated generation 16 brings Writer 0.15.2, Sheets 0.16.1, PDF 0.18.2
  and Slides 0.15.1, retaining GREYWARD identity, desktop associations and the
  existing signed DNF5 Update Center channel.

## Known limitations

- No complete clean-install, encrypted-root/recovery, physical printing or broad
  hardware acceptance was performed for this image. Composition and publication
  do not certify those workflows. Starting a test VM does not establish them.
- A real bounded probe produced an automatically refreshed 3/6 row in the actual
  reference Security Center. Other elevated levels were exercised with isolated
  fixtures, not a live-malware acceptance campaign. Full EDR coverage is not
  claimed; missing evidence must remain visible and is not proof of safety.
- The previously reported Bazaar Explore recurrence has no confirmed durable
  correction in this release. App installation and Explore are distinct paths.
- Complete Microsoft Office/LibreOffice format compatibility is not promised.

The existing ISO is reused for publication; no rebuild is performed. Personal
VPN profiles, credentials, developer tools and SSH server access are not default
image components.
