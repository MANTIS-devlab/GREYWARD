## Changes since 0.5.6

- Security Center includes the newer recovery and update behavior. Network Activity builds one history from OpenSnitch and host firewall evidence, with inbound flows, verdicts and deduplication.
- Mail installs the official MailCraft RPM with the GREYWARD launcher, dark appearance and a default desktop shortcut. The refresh service verifies upstream release metadata before presenting newer RPMs to Update Center. The desktop shortcut action also uses the effective launcher from the desktop application registry.
- Bazaar retries Explore when the interactive store has no catalogue. The local catalogue remains available when present.
- The Plymouth theme uses the revised unlock animation and monochrome design.
- The factory verifies drivers and firmware in the actual installer initramfs and selected target RPMs. It checks representative Intel, AMD and NVIDIA PCI aliases and checks the embedded BIOS and UEFI boot configurations. The installer can rediscover USB or optical media using the embedded payload digest.
- The installed rescue entry starts a console with kernel modesetting disabled while keeping LUKS and the confirmed keyboard map. The normal and rescue initramfs retain common storage and keyboard modules.

## Validation

The final ISO passed media, BIOS and UEFI configuration, offline package
closure, and static hardware inventory checks. On Hyper-V Generation 2
with Secure Boot enabled, the exact ISO booted to the keyboard confirmation
screen. Full installation, encrypted boot from the installed disk and
physical hardware coverage remain outside this validation.

The four customized ArtCraft applications use the same signed generation-16
packages as 0.5.6. Their matching source RPMs are in the
[0.5.5 release files](https://sourceforge.net/projects/greyward/files/v0.5.5-sophon/).
Mail uses the official MailCraft 0.14.0 RPM.
