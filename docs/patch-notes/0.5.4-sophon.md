## Changes since 0.5.3

- ClamAV integration: automatic scanning of arrivals in Downloads/Desktop and
  authorized removable media, database freshness, user-scoped scan records and
  file properties, persistent results and deduplicated native notifications.
- Behavioral intelligence in the existing Network Activity and Security History
  views: explainable assessments, clearer policy outcomes, refined attribution
  and bounded collection. This is observation-only; a heuristic score does not
  automatically kill a process or establish compromise.
- Desktop stability: protected-session/readiness lifecycle corrections,
  Quickshell graph crash repair, reduced background work and KVM monitor recovery.
- Appearance: refined scan results, readable country flags, white application/
  domain icon backplates and canonical 180% taskbar application icons.
- Screenshot editor: native window controls, supported dark styling, GREYWARD
  identity and working Save As/error feedback. Mouse-area capture remains
  available without Polkit, with protected-frame exclusion.
- Installer: English/US initial setup with a clear native keyboard confirmation.
  The irrelevant empty Software Selection page is hidden for the fixed offline
  package set. This does not enable arbitrary package selection.
- Retains the accepted Polkit/lock designs, offline firewall-loop correction,
  Strata-only file management and signed Office generation-9 update integration.

## Sources and validation

The frozen source archive contains 5278 project files with original/
published hashes, executable modes, source origins and fifteen selected RPM
inputs in `ISO-GREYWARD-0.5.4-Sophon-source.tar.gz-MANIFEST.json`. It uses engineering snapshot `423142a` and
the exact validated Security Center 133 / Context 132 source bytes. Twenty-four
files differ from the composition export only by CRLF/LF endings; the original
validated bytes are retained. Private history, credentials, personal settings
and host-access configuration are excluded; documentation is sanitized.

The four accompanying signed Office source RPMs include the prepared engines,
GREYWARD adaptations, locked vendored Cargo dependencies, fonts/resources and
notices. Their filenames identify the generation embedded in this ISO. Other
upstream inputs are pinned by the owning build manifests. Use these frozen
sources for this image; GitHub main is not necessarily its exact build tree.

Native image tests: 83 passed. Native Rust tests: 215 passed, 22 explicitly
ignored. Offline dependency/transaction checks and actual offline installation
of all four default Flatpak applications passed during composition. Independent
Windows media readback verified the SHA-256, complete payload hashes, 40 required
paths and all fifteen selected RPMs in both embedded locations. The runtime
inventory contains 1,148 RPMs. This is not a bit-reproducible or signed-ISO claim.

## Known limitations

- Bazaar Explore displayed “Can't Reach Flathub” on an installed 0.5.4 test
  system while app installation remained functional. It recovered during
  investigation after an update/relaunch, but the initial API error was not
  captured. A durable correction is **not** claimed or added to this ISO.
- Behavioral sensor availability depends on the kernel/hardware. Missing
  coverage must remain visible; full EDR coverage is not claimed.
- Full clean-install, encrypted-root/recovery, physical printing and broad
  hardware acceptance remain separate. Composition tests do not certify them.
- Complete Microsoft Office/LibreOffice format compatibility is not promised.

No ISO was rebuilt for publication. Personal VPN profiles, credentials,
developer tools and SSH server access are not default image components.
