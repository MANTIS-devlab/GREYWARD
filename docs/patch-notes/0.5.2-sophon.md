## What is included

- Writer, Sheets, PDF and Slides are four native, independent applications built
  on ArtCraft's WordCraft, GridCraft, PdfCraft and DeckCraft. Credit for their
  engines and interfaces belongs to ArtCraft and the upstream contributors.
  GREYWARD provides downstream packaging, names, icons, dark surfaces and desktop
  associations; these are customized builds, not official ArtCraft releases.
- Coordinated application tiles and separate document icons, Software pinned as
  an ordinary application, and refreshed Software/image-viewer/Settings artwork.
- Default Home, Trash, Writer, Sheets, PDF, Slides, Brave and Terminal desktop
  entries. The six exact factory application copies receive native launcher
  trust at first login; unrelated and customized executables remain separate.
- Bazaar Explore cold-cache recovery, plus the earlier verified Flatpak
  installation and origin-restoration fixes and the curated Software banner.
- DMS 2.0 bar and Overview layout, darker palette, native per-widget backgrounds,
  Network Identity retaining the last IP during refresh, and multi-output icons.
- Protected USBGuard approval, the offline firewall/Polkit-loop correction,
  accepted Polkit design and GREYWARD lock wallpaper/clock design.
- Security-update/restart and optional microphone/camera-start notifications.
  VPN interruption notifications remain excluded.
- Mouse-area screenshots and Swappy, without per-capture Polkit, with the
  protected-frame boundary and region/Escape workflow retained.

Strata remains the file manager. OBS, QTerminal, Haruna, Collabora and Papers are
not default applications. Personal VPN profiles/MTU/keys, user data, developer
accounts/tools and SSH server access are not image defaults.

## Sources and verification

The frozen source archive contains the GREYWARD source/build inputs and a
per-file manifest, with an explicit separate snapshot for the Center/Context
pair. Private Git history and host-access configuration are excluded; docs are
sanitized. The four accompanying Office `.src.rpm` files contain the prepared
engines, locked Cargo dependencies, fonts and resource notices. Original
licenses and upstream attribution are retained. Other upstream inputs are pinned
by the owning manifests. Current GitHub main is not the frozen ISO source.

ISO composition, networkless dependency/Flatpak verification and Linux/Windows
media readback pass. All 13 selected RPMs match in both embedded locations,
with nine canonical-file checks. This is not a bit-reproducible or signed-release
claim. Complete clean installation, recovery, physical printing and broad
hardware acceptance remain unverified. The Office public update feed is not
operational. Complete Microsoft Office/LibreOffice compatibility is not promised.

Verify with `sha256sum -c GREYWARD-0.5.2-Sophon-x86_64.iso.sha256`, or compare
PowerShell `Get-FileHash` with the SHA-256 above. See the companion provenance and
verification JSON files for exact recorded evidence.

strict host-key checking. Full SFTP readback matches all 5,147,983,872 ISO bytes
and its SHA-256. All ten companions were read back and matched individually,
