# Network identity marks

These local SVG marks are vendored from Simple Icons 16.28.0:

https://github.com/simple-icons/simple-icons/releases/tag/16.28.0

The catalog contains the complete 3,453-icon release set and a generated local
alias index. Icons are used only as small, best-effort identity cues for
OpenSnitch application and destination evidence. Matching, loading, and color
data are all local; viewing activity never performs a remote favicon, website,
or icon-service request. Unknown applications and domains use GREYWARD's local
generic fallback.
